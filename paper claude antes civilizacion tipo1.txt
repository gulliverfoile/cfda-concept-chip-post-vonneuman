## 📚 Las Cinco Piezas

### 1. TUSE: Teoría Unificada de Sistemas Emergentes

📁 `/teoria/TUSE.pdf`

**Qué dice:**

Los sistemas complejos (células, cerebros, sociedades, IA) 
funcionan según principios comunes:

**Circularidad Abierta:**
- Retroalimentación que conserva coherencia
- PERO permite bifurcaciones y entrada de novedad
- No cerrado (= muerte por rigidez)
- No completamente abierto (= colapso por caos)

**Recursión Dinámica:**
- Cada nivel reproduce el PATRÓN, no la estructura literal
- Células → Órganos → Organismos (mismo patrón, diferente escala)
- Permite adaptación y variabilidad contextual

**Gestión Condicional de Entropía:**
- La entropía no dirige, pero condiciona
- Ignorarla tiene consecuencias
- Gestionarla permite orden sin violar termodinámica

**Identidad Funcional:**
- Tu identidad no son tus átomos (cambian constantemente)
- Es el PATRÓN de relaciones que persiste
- Barco de Teseo resuelto

**Estado:**
- ✅ Coherente internamente
- ⚠️ Sin formalización matemática completa
- ⚠️ Probablemente reinventa ruedas (Varela, Prigogine, etc.)
- ❌ No falsificable en forma actual

**Conexión:** Esto es el "por qué" funciona todo lo demás.

### 5. Entropy Mapper: Diagnóstico en Tiempo Real

📁 `/herramientas/entropy-mapper/`

**Qué hace:**

Visualiza procesos del sistema operativo como sistemas
que generan entropía (calor/ineficiencia):
```python
def _calculate_architectural_entropy(self, mem, io, cpu):
    """
    NO mide "uso de memoria"
    Mide "patrones de acceso que generan calor"
    """
    entropy = (
        mem_pattern * 0.4 +  # Localidad vs aleatoriedad
        io_burstiness * 0.3 +  # Bursts son ineficientes
        cpu_volatility * 0.3   # Cambios frecuentes = entropía
    )
    return entropy
```

**Implementa TUSE:**
- Mide gestión de entropía en tiempo real
- Identifica donde el sistema viola principios
- Sugiere reorganizaciones

**Estado:**
- ✅ Código funcional con visualización
- ⚠️ Métricas simplificadas
- ⚠️ Versión actual usa randoms (!!)
- ❌ Necesita performance counters reales

**Conexión:**
- Herramienta para MEDIR si sistema cumple TUSE
- Diagnóstica proto-kernel en vivo
- Base para optimización predictiva
